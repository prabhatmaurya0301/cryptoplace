# CryptoPlace

A cryptocurrency price tracking web application built with React and CoinGecko API.

## 🚀 Live Demo

[View CryptoPlace Live](https://cryptoplace-2va1xbjth-beru7.vercel.app)

## 🛠️ Tech Stack

- React.js
- Vite
- JavaScript
- React Router
- Context API
- CoinGecko API
- Vercel Serverless Functions
- CSS

## ✨ Features

- Real-time cryptocurrency prices
- Search cryptocurrencies
- USD, INR and EUR currency support
- Individual cryptocurrency details
- Historical price chart
- Market rank, market cap and 24-hour high/low
- Responsive UI
- Secure server-side API integration
